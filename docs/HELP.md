# 使用指南

连接本机 Clash Verge，查看节点延迟，让选定代理组按你的规则自动切换。

## 快速开始

1. 运行 Clash Verge，确认代理服务已启动。
2. 打开智能节点管家，点击“自动发现”。
3. 在“代理组”中选择要管理的 Selector 组，点击“立即测速”查看节点表现。
4. 在 Clash Verge 中启用系统代理或 TUN，然后进入“自动切换”页，点击“开启自动切换”。

“立即测速”用于查看延迟；“开启自动切换”会按已保存的规则管理当前组。系统代理、TUN 和路由模式在 Clash Verge 中设置。

## 连接设置

**优先使用自动发现。** 软件会查找本机 Clash Verge 配置及 Mihomo 命名管道。连接成功后，首页显示控制器与代理状态。

**手动填写控制接口。** 在 Clash Verge 设置中查找“外部控制器 / External Controller / Mihomo API”，设置本机地址和密钥。然后在本程序“连接与设置”中填写对应地址与密钥，保存后重新检测。

控制地址示例：`http://127.0.0.1:9090`。9090 可换成空闲端口；代理流量端口与控制端口分别配置。

如果通过全局 Merge / 扩展配置启用控制器，可在该入口保存并应用：

```yaml
external-controller: 127.0.0.1:9090
secret: "你的随机密钥"
```

控制接口绑定 `127.0.0.1` 等本机回环地址，并为它设置密钥。使用 Clash Verge 提供的全局扩展入口，保留订阅和生成的运行配置原有内容。

## 自动切换

**何时切换。** 默认每 60 秒检测一次，首次开启立即检测。当前节点延迟在 120 ms 以内时保持；超出阈值或测速失败时，从组内成功测速且未排除的服务器中选择延迟最低者。

候选节点整体延迟偏高时，仍会选择其中更快的节点，并保留高延迟提示。当前节点已经最快时继续使用它；每轮最多切换一次，切换后读取实际节点确认结果。

**控制节奏。** 最小切换间隔默认为 60 秒，可在设置中调整。测速轮次依次执行，较长的一轮完成后再安排下一轮。

**暂停与关闭。** 两个操作都会停止后续自动任务，并保留当前节点。已提交的请求完成后，界面显示实际结果。再次点击“开启自动切换”即可继续。

测速期间在 Clash Verge 手动选了新节点，本轮会保留你的选择，下一轮再重新评估。

## 测速与候选

- **管理范围：** 选择一个可手动控制的 Selector 组，测速对象为该组的直接服务器成员。URLTest、Fallback 等组由 Mihomo 管理；当前选择为嵌套组时，可先在 Clash Verge 选择实际服务器，或换一个管理组。
- **排除地区：** 默认排除香港和新加坡。排除影响自动切换候选，测速表仍展示这些节点。
- **并发与超时：** 自动并发按当前组节点数调整，最多 8 个；也可手动设置。单节点超时默认 5000 ms。较短超时遇到 Mihomo 504 时，会按 5 秒预算重试一次。
- **地区编辑：** 点击输入框展开列表，输入文字搜索或添加自定义地区。标签上的关闭按钮删除单项，右侧清空按钮移除全部选择。方向键切换选项，Enter 选择，Esc 收起。

修改参数后点击“保存设置”。当前测速使用原规则，新规则从下一轮检测生效。保存连接地址或密钥时，软件会在当前任务结束后重新连接；连接和代理状态验证通过后，恢复原先的自动运行状态。

## 常见问题

**找不到控制接口**

先确认 Clash Verge 已启动，再点击“自动发现”。需要手动连接时，按“连接设置”中的步骤核对本机控制地址、端口与密钥。Clash Verge 的设置入口名称因版本而异，可查找 External Controller 或 Mihomo API。

**系统代理或 TUN 显示“状态无法确认”**

在 Clash Verge 中启用其中一种模式，再重新检测。系统代理应指向当前 Mihomo 的本机 HTTP / 混合端口；TUN 应同时处于内核已开启、对应网卡活动的状态。自动切换在确认这些条件后开始；查看节点延迟可使用“立即测速”。

**节点测速失败**

先在“测速地址”中换用可访问的 204 地址，再比较多个节点。延迟反映节点访问该测试地址的往返时间。全部候选测速失败时会保留当前节点，检查连接后可再次测速。

**没有发生自动切换**

查看“自动切换”页的状态与规则：当前节点是否超过阈值、是否存在成功测速且未排除的候选、最小切换间隔是否已到达。运行日志会显示本轮保持或切换的原因。

## 日常使用

- **后台运行：** 默认关闭窗口后收进托盘，双击托盘图标恢复。通过顶部“退出”按钮或托盘菜单结束程序；自动运行中退出会显示确认。
- **查看日志：** “运行日志”支持跟随最新记录和打开日志目录。向上滚动可阅读历史，“清空显示”整理当前视图，文件日志继续保留。
- **保存密钥：** 勾选“使用 Windows 账户加密保存密钥”后，密钥由当前账户加密保存；取消勾选后，本次启动期间使用该密钥。
- **查找配置：** 配置和日志保存在 `%LOCALAPPDATA%\ClashSmartSwitcher`。配置文件为 `settings.json`，日志在 `logs` 子目录；日志滚动保留约 10 MB。

软件通过本机控制接口协同 Clash Verge，节点、配置和日志保存在本机。升级时退出旧版，将新分发包解压到新目录，现有用户设置会继续使用。
