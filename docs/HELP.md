# 连接 Clash Verge

这是独立的第三方工具，不是 Clash Verge 官方软件。程序不会修改系统代理、TUN、路由模式、订阅或 Clash Verge 配置。

## 首次连接

1. 先运行 Clash Verge，并确认代理服务正常。
2. 点击“自动发现”。程序只读取三种已知的用户配置目录，优先尝试 Mihomo 官方本机命名管道。
3. 连接成功后，在“代理组”中选择需要管理的组。只支持可手动控制的 Selector 组。规则模式可能同时使用多个组，无法可靠推断时必须自己选择。
4. 先点击“立即测速”。这只测速，不会修改当前节点。
5. 在 Clash Verge 中启用系统代理或 TUN，再点击“开启自动切换”。

## 自动发现失败：启用本机 HTTP 控制器

不同版本的 Clash Verge 设置入口可能不同。到 Clash Verge 的设置中查找“外部控制器 / External Controller / Mihomo API”，将其设置为本机地址，例如 `127.0.0.1:9090`，并设置一个自己的密钥。端口可自行选择空闲端口，不能与代理流量端口重复。

如果该版本只支持通过全局扩展配置启用控制器，请在 Clash Verge 支持的全局 Merge / 扩展配置入口中加入以下字段，再由你自己保存并应用。不要直接覆盖订阅配置或生成的运行文件：

```yaml
external-controller: 127.0.0.1:9090
secret: "换成你自己的随机密钥"
```

返回本程序“连接与设置”，填写 `http://127.0.0.1:9090` 和对应密钥，点击“保存设置”和“重新检测连接”。上面的 9090 只是示例。7897 等混合端口通常是代理流量入口，不是控制接口。**不要使用 0.0.0.0，不要将控制器暴露到局域网或公网。**

如果版本不允许启用 HTTP，且命名管道不存在或权限不兼容，请先查看该版 Clash Verge 的官方设置说明。程序不会尝试私有 IPC 协议，不会要求管理员权限。

## 节点选择规则

默认每 60 秒刷新一次所选组的直接服务器节点，首次开启立即检测。当前节点不超过 120 ms 就保持。超过阈值或测速失败时，选最低延迟的合格节点，默认排除香港和新加坡。自动模式最多同时测速 8 个节点，也可以在设置中手动调整；切换代理组后会重新按新组节点数限制上限。这样可以避免大量节点同时建立连接导致 Mihomo 返回超时。若单节点超时设置低于 5 秒且 Mihomo 返回 504，程序会用 5 秒预算自动重试一次，再判定测速失败。特殊策略与嵌套代理组不作为服务器；选中的条目是嵌套组时，该轮只测速并提示你选择实际服务器或更合适的管理组。

设置页的数值项可以直接输入，也会显示允许的最小值和最大值；鼠标滚轮不会改变数值，避免在滚动设置页时误改参数。点击“排除地区”输入框可展开多选列表，候选地区从当前代理组的直接服务器节点名称识别，切换组或重新连接后更新；已选地区会保留。输入文字可搜索，也可选择添加未识别的自定义地区。已选地区显示在框内，点击标签右侧的关闭按钮可单独删除，右侧清空按钮可移除全部选择。方向键切换选项，Enter 选择，Esc 或点击外部收起列表；修改后点击“保存设置”持久保存。

每轮最多切换一次，切换后重新读取实际节点。最小切换间隔默认 60 秒，可设为 0；它只限制切换频率，不改变阈值。较长的测速轮次不会与下一轮重叠。

自动切换或测速期间也可编辑设置，修改后需要保存。当前测速保留原规则，新规则从下一轮生效；未保存内容不影响运行，也不会被后台结果覆盖。保存地址或密钥后，软件会等待当前任务结束并重新连接。“重新检测连接”和“自动发现”在验证通过后恢复原自动运行状态；检测失败、代理状态不满足或你主动暂停时保持停止。后台结果只在界面与日志中显示，不弹出系统提醒。

程序只管理你选择的一个代理组。你在 Clash Verge 手动改了节点，程序会读取最新状态；如果在本轮测速期间改了节点，本轮取消自动切换。规则模式里更改其他组并不意味着本程序会自动改管那个组。

## 状态无法确认

系统代理必须指向当前内核的本机 HTTP/混合端口；PAC 或其他软件的代理可能无法确认。TUN 必须由实时 API 报告开启，并检测到对应活动网卡。仅读取配置文件、进程存在或“规则 / 全局 / 直连”均不足以确认。两者均未可靠确认时，自动切换被阻止；立即测速仍可使用。

## 测速失败

Mihomo 单次测速失败不能可靠区分“节点坏了”与“测试网站不可达”。本程序会显示这项不确定性，不把失败伪造成正常延迟。全部失败时不切换，建议在设置中换用可访问的 204 测速地址，再比较多个节点。测速是内核到所填网站的往返测试，不是保证所有网站都快。

## 暂停、关闭与退出

暂停和关闭都停止定时任务，不修改当前节点或代理服务。已发出的网络请求需要等待有限超时结束，已提交的切换请求无法撤回，程序会读取实际结果。关闭会保存关闭状态；暂停保留当前设置供手动重新开启。点击窗口关闭默认隐藏到托盘，双击托盘图标可恢复；真正退出请使用“退出”按钮或托盘菜单。运行中退出会请求确认。

## 配置与日志

默认目录是 `%LOCALAPPDATA%\ClashSmartSwitcher`。配置为 `settings.json`，日志位于 `logs`；日志单文件最多 2 MB，最多保留 5 份。密钥使用 Windows DPAPI 绑定当前 Windows 账户加密；不选择加密保存则仅存在于本次进程内存。不要把配置从一个账户复制到另一个账户后期待密钥仍可解密。配置损坏会备份后恢复默认值。

“清空显示”只清空屏幕日志；文件日志仍保留。程序不上传日志、节点、订阅或密钥。
