## 自动化测试

此前完整测试记录为 81 项通过，记录见 `verification/test-results-final.xml`。当前受限执行环境会拒绝模拟 Windows 命名管道创建，并可能拒绝 pytest 临时目录访问；这两项限制不影响真实 Mihomo 命名管道探针或发布包冒烟测试。

V1.1.1 首次发布回归：89 项通过，1 项命名管道测试因执行环境拒绝访问而排除；该项曾实际运行并报 WinError 5，不能视为通过。测试进程使用默认权限创建临时目录以兼容受限环境。另在原生 Windows Qt 平台运行桌面和地区多选相关测试，16 项通过；检查了 1120 像素及 850 像素窗口宽度下的标签换行、浮层位置和横向滚动情况。地区候选更新与保存恢复使用模拟代理组验证，未执行真实代理切换。

V1.1.1 滚轮修复重发回归（2026-10-15）：原生 Windows Qt 平台 98 项通过，仍排除上述 1 项权限受限的命名管道测试。地区组件专项测试 17 项在 Windows 和 offscreen 平台均通过。使用准确全局坐标的 `QWheelEvent`，分别从原生 `QWindow` 和列表 viewport 注入，验证长列表向上/向下、顶部/底部边界、搜索和选择不变、后续多选/取消/删除/清空、外部点击/Esc、设置页正常滚动以及反复开关/销毁后的事件监听器清理。额外验证了 Qt 样式对象的内部 FocusIn 不会关闭面板、原生窗口层输入框点击可切换展开状态。1120 和 850 像素窗口截图确认浮层位置稳定。以上为 Qt 事件注入验证，未进行人工物理滚轮验收；系统级鼠标注入未能可靠到达测试列表，因此不作为通过依据。
