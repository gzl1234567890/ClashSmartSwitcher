# V3.1.1 UI 修复验证

日期：2026-10-17。环境：Windows 11 x64（10.0.26200）、Python 3.12.15、
PySide6 Essentials / shiboken6 6.10.3。

## 问题与修复

- MotionButton 分步绘制背景和图标文字时，label 使用了整个按钮边界，绕过 QSS
  内边距。改为先读取 `SE_PushButtonContents`；侧栏使用稳定的透明边框预留焦点位置。
- 未测速等占位文字原来与数字一样右对齐，现居中；测速数字仍右对齐，状态列居中。
- 工具提示统一 8px/12px 留白。Windows QRollEffect 的滚入表面会短暂裁切文字，
  禁用提示框的滚入/淡入，使原生文字立即完整呈现；其他共享动效保持。
- 普通控件外高 38px、侧栏行 48px、表格行及表头 44px、图标 18px、关联间距 8px。
  总览节点摘要预留五行和一个表头，避免行高与容器不一致。
- 不变更字体来源、字号、节点选择算法、配置格式或后台任务与静默策略。
