# 3.2.1 字体、图标与帮助中心验证

日期：2026-10-28。环境：Windows 11 x64（10.0.26200）、Python 3.12.15、PySide6 / Qt 6.10.3、PyInstaller 6.19.0。

## 本次交付

- 原生控件和帮助正文以随包的 Clash Sans SC 为主字体，使用真实 400 / 500 / 600 字重，统一平滑轮廓、抗锯齿和分数缩放策略。
- 原生字体探针确认：此前 Microsoft YaHei UI 会将请求的 500 匹配成 400、600 匹配成 700；新字体按真实字重匹配。该证据解释字重差异；用户截图中每一个细小断点的成因以实际显示环境为准。
- 帮助中心分为六个章节，桌面提供目录，紧凑窗口使用章节选择器；正文为 15px / 25px 行高，代码统一为 Consolas 14px，并保留中文回退。
- 新图标由内置 imagegen 生成，保留 1254px 原始高清源图；按用户授权清理导出边界，提供 1024px 高清成品、256px PNG 和 16–256px 十档 ICO。窗口、托盘、应用栏与 EXE 使用同一图标。
- README 和使用指南围绕用途、操作与行动式排查组织，保留具体参数、控制条件和本机配置方法。

## 功能与视觉验证

- 最终源码原生 Windows 完整回归 **153 项通过，35.67 秒**。包含通信、配置、规则、线程、字体真实字重、富文本字重、章节切换、紧凑布局、代码字体、焦点、表格、托盘与退出。
