# 真实环境手动验收

请在自己的 Clash Verge 中完成；模拟测试不会代替这些真实验收。

| 检查 | 操作与预期 |
|---|---|
| 首次启动 | 解压完整 ZIP，运行 EXE；不需要 Python，不应要求管理员权限。 |
| 自动连接 | Clash Verge 正在运行，点击自动发现；应显示内核版本和实际代理组。 |
| 手动连接 | 在本机启用 HTTP 控制器，输入真实地址与密钥并保存；错误密钥给出中文提示。 |
| 状态门禁 | 在 Clash Verge 关闭系统代理和 TUN，开启自动切换应被阻止；分别开启其中一种后再检测。 |
| 路由模式 | 仅改成“规则/全局”且未启用代理/TUN，不应通过门禁。 |
| 单组范围 | 选择含实际服务器的 Selector；表格来自该组，其他组当前节点不应被改变。 |
| 立即测速 | 点击立即测速，延迟来自本次请求，当前选中节点不应被改变。 |
| 阈值 | 在设置调整阈值并保存后，观察当前延迟低于或等于阈值时保持；高于阈值时最低延迟合格节点被选中。 |
| 地区 | 香港、新加坡即使最快也不得成为自动目标；修改排除项后按新设置判断。 |
| 切换验证 | 查看原节点、目标、实际状态验证的日志，并在 Clash Verge 核对。 |
| 手动切换 | 测速期间在 Clash Verge 改节点，软件本轮应取消自动切换并保留你的选择。 |
| 失败恢复 | 停止 Clash Verge，窗口仍可操作；重启并重新检测应恢复。 |
| 运行中编辑 | 自动切换和测速中可修改、保存设置；未保存草稿不改变运行规则且不被后台覆盖，保存后下一轮使用新规则。 |
| 重新检测 | 自动运行中重新检测或自动发现，成功后恢复原运行状态；失败、代理门禁不满足或主动暂停则不恢复。 |
| 修改连接 | 自动运行中保存新地址/密钥，等待旧任务结束后连接最新值，验证成功后才恢复。 |
| 静默后台 | 最小化后切换成功或异常仅记录日志与界面提示，不弹通知、不自动打开窗口。 |
| 测速网站故障 | 临时换一个不可达测试地址，应显示无有效数据，全部失败不切换。 |
| 防抖 | 较短检测间隔、较长最小切换间隔，日志说明等待间隔；阈值不被改变。 |
| 暂停与关闭 | 两者不应改变当前节点、系统代理、TUN、路由模式，且后续无定时测速。 |
| 托盘 | 运行中最小化和关闭窗口仍检测；双击托盘恢复。单击显示简要状态。 |
| 单实例 | 再次双击 EXE，应唤起现有窗口，无第二套检测日志。 |
| 真正退出 | 运行中退出可取消；确认退出后等请求结束，任务管理器无残留本软件进程。 |
| 配置损坏 | 先退出软件，备份 settings.json 后将其改为无效 JSON；重启恢复默认且保留损坏备份。 |
| 密钥保护 | 配置文件没有明文密钥；同一 Windows 账户重启能解密。 |
| 分辨率 | 1366×768、1920×1080、125%/150%缩放检查；表格和设置可滚动，文字不重叠。 |

每项记录日期、Windows 版本、Clash Verge 版本、Mihomo 版本及结果。真实切换的测试应由你在可接受节点变化的时间执行。
